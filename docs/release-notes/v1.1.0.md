# v1.1.0 - automated tests and release pipeline

No change to the command line: modes, parameters, exit codes and the CSV format are the same as in v1.0.0.

**What's new**
- Pester 5 test suite (`tests/`) that runs without a reader, a card or the Smart Card service:
  profile parsing, response parsers, card-type classification, the exact APDUs sent for a profile,
  and regression tests for the PowerShell pitfalls this toolkit has already hit
- CI on every push and pull request: PSScriptAnalyzer plus tests on Windows PowerShell 5.1 and PowerShell 7
- Releases are built by GitHub Actions from the tag: runtime-only ZIP plus `SHA256SUMS.txt`
- Both scripts can be dot-sourced to load their functions without touching PC/SC
- Documentation: examples no longer reference deployment-specific names or serial numbers

**Requirements:** Windows 10/11, PowerShell 5.1+; HID OMNIKEY CCID driver recommended. See README for details.

Verify your download against `SHA256SUMS.txt`:
`Get-FileHash .\omnikey-provisioning-toolkit-v1.1.0.zip -Algorithm SHA256`
