# v1.2.0 - one entry point, reader model detection, OMNIKEY 3121

The existing command lines are unchanged: `CheckProfile5022.ps1` and `Batch-Omnikey5022-Provision.ps1` accept the same parameters and return the same exit codes, and they write the same CSV and console output (compared against output recorded on an OMNIKEY 5022).

**What's new**
- `Omnikey.ps1`: one command for everything (`get`, `set`, `verify`, `export`, `testcard`, `batch`, `readers`, `configure`), with an interactive menu that returns after each action
- `configure`: set a reader by answering questions (current value as default); only the changed parameters are written, and the answers can be saved as a profile
- `get` shows the configuration values in green
- Reader model detection: the toolkit asks the reader for its model, writes only the parameters that model supports and never writes to an unknown model; `readers` lists connected readers and what can be configured
- **OMNIKEY 3121** (contact reader): `contactSlot` profile keys (`enabled`, `operatingMode` iso7816/emvco, `voltageSequence`), plus Get/Set/Verify/Export and a contact card test (verified on hardware); in EMVCo mode the 3121 reports a 5V-only voltage sequence, so profiles combining EMVCo with other voltages are rejected
- Profile validation before any write: unknown keys (typos), wrong value types, unsupported bit rates or voltages, and keys the reader model does not have
- Implementation moved into the `OmnikeyToolkit` PowerShell module; the scripts are thin wrappers around it
- Test suite rebuilt around the module: simulated 5022/3121 readers, console output checked against hardware recordings, batch verification by serial

**Upgrade notes**
- Unpack the whole ZIP: the scripts need the `OmnikeyToolkit` folder next to them. On a fresh machine unblock all files: `Get-ChildItem -Recurse -File | Unblock-File`
- A profile containing a typo or an invalid value now stops with exit code `1` instead of being silently ignored
- OMNIKEY 5422/5122 support follows HID's sample code and is not yet verified on hardware (a note is printed)
- Batch mode needs reader serial numbers; OMNIKEY 3121 does not report one, so configure 3121 units with `set` / `verify`

**Requirements:** Windows 10/11, PowerShell 5.1+; HID OMNIKEY CCID driver recommended. See README for details.

Verify your download against `SHA256SUMS.txt`:
`Get-FileHash .\omnikey-provisioning-toolkit-v1.2.0.zip -Algorithm SHA256`
